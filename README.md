📟 Super Mercado!!! 🖥️

Programa simples de um sistema de mercado desenvolvido em Python, com objetivo de cadastrar e gerenciar produtos. Ele utiliza listas, funções, estruturas de repetição e tratamento de erros.

O usuário pode estar cadastrando os produtos informando nome e preço | visualizar a lista de produtos | calcular o valor total do carrinho |  identificar o produto mais barato | mostrar os produtos com preço acima de mil reais.

O programa também utiliza a biblioteca COLORAMA para adicionar cores ao terminal, deixando a interface mais interativa e agradável. 

Além disso, possui validações para evitar nomes vazios e preços inválidos, garantindo um melhor funcionamento do sistema.
